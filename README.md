# AI-ML-Engineering-Journey

One universal repository for the AI Engineer learning journey, following the supplied **AI Engineer Roadmap 2027**. The roadmap has 23 modules and a target of 137 topics. Topic work is added progressively; undocumented topics remain pending rather than being inferred.

## Repository map

- [`modules/`](modules/) contains all roadmap-aligned learning notes, implementations, experiments, notebooks, and module-specific projects.
- [`ROADMAP.md`](ROADMAP.md) tracks the exact supplied module titles and topic-level progress where details are available.
- [`CONTRIBUTING.md`](CONTRIBUTING.md) and [`docs/DEVELOPMENT.md`](docs/DEVELOPMENT.md) describe contribution and development conventions.

## Working conventions

- Preserve module numbering and exact roadmap titles.
- Put topic work and related projects inside their respective module.
- Add material as it is learned; do not create dummy implementations or fill in unavailable topic details.
- Give substantial projects focused documentation, source, tests, and dependencies when appropriate.

See [`ROADMAP.md`](ROADMAP.md) for documented topics and pending source details.
